Static site · public APIs · browser calculations

Explore public humanitarian data without overclaiming what it can say.

This static website pulls small or comprehensive samples from public data sources, shows what comes back, and performs light browser-side calculations. It is not a forecast, risk score, or official analysis. Use it to inspect signals, coverage, recency, and data limitations.

Start with data tools Try trend extension

What “comprehensive” means here

Where an API supports paging, the site can fetch multiple pages up to a browser-safe cap. Where an endpoint exposes only a latest feed or a metadata list, “comprehensive” means “all records returned by that public endpoint”, not all data the organisation holds.

Statistical analysis

Simple trend extension, not forecasting.

This uses World Bank time-series data already available to the browser. It calculates basic change over time and a simple linear continuation to a selected year.

What to do now regarding statistical analysis: do not install R, SQL, or a database yet. This page now performs the appropriate first level of analysis in JavaScript: latest value, data recency, absolute change, percentage change, average annual change, linear trend line, and “if recent pattern continued” extension. Use this to learn what the product should do before adding heavier tools.

About the data sources

Sources currently used by this site.

Only active, browser-safe sources are listed. Removed sources include direct ACLED, direct WHO GHO, ReliefWeb, HDX HAPI, FEWS NET, and ACAPS because they require credentials, app identifiers, approval workflows, or did not behave as no-friction browser sources in this setup.
