about the calculations

How it works

This page keeps the technical explanation away from the main user flow. The output is a transparent case-building aid, not an official forecast.

In plain terms

  • The simulator retrieves historical country-level indicators from the World Bank.
  • It removes blank, null and future-year rows before calculating anything.
  • It extends each usable historical pattern into the selected year using a built-in calculation chosen for that indicator type.
  • It separately retrieves current/contextual records from GDACS and UNHCR.
  • It does not predict conflict, disasters, displacement shocks or humanitarian need.

What “usable historical values” means

A usable historical value is a source row with a real number and a valid year not later than the current year. Blank values are ignored. Zero is kept only when the source explicitly reports zero.

What the Black Swan stress-test does

The Black Swan section is an experimental stress-test. It injects a rare, high-impact disruption after the numeric case file has been generated, then shows which assumptions become fragile. It is not a prediction engine.
