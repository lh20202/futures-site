Futures Site - Live Data Source Tester

This is a prototype for testing live humanitarian, health, displacement, conflict, climate, disaster, and risk data sources. Each card fetches a small sample from the source and shows whether the connection works.

0 public live fetch tests are wired for this static prototype; browser CORS policy still determines whether each one succeeds.

Next architecture step

A static site can test public browser-accessible APIs. For sources requiring API keys or complex downloads, the next step is a small backend/serverless proxy so keys are not exposed in the browser.
