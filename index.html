Public data demo

Data Playground

Use public humanitarian, displacement, disaster, population, climate, and development data sources to pull small live samples into the browser.

Choose a source, press the button, and inspect what comes back. This page is not producing forecasts or official analysis. It is showing which public sources the site can retrieve and how those sources might support future humanitarian questions.

Some tools pull actual data values. Others search dataset catalogues, which means they help find relevant datasets rather than loading the full dataset.

Live data

The site pulls actual values or records directly from a public source.

Dataset search

The site searches a catalogue and returns dataset records, descriptions, and links.

Public indicator

The site pulls a country-level indicator that can give context, but it is not a complete explanation on its own.

UNHCR displacement data

Fetch a small sample of displacement and refugee population data.

Source: UNHCR Refugee Data Finder API

What this source tells you

UNHCR provides data on refugees, asylum-seekers, internally displaced people, stateless people, and other displaced populations.

Why this might be useful

Use it to understand where displacement pressures are visible in official population data.

What this button pulls

A small sample of recent displacement population records.

HDX humanitarian dataset search

Search a humanitarian dataset catalogue by keyword.

Source: Humanitarian Data Exchange

What this source tells you

HDX is a humanitarian data catalogue. It helps find datasets from humanitarian organisations, governments, UN agencies, NGOs, and research bodies.

Why this might be useful

Use it to find datasets related to displacement, food security, health, climate, access, conflict, or response operations.

What this search pulls

The site searches HDX dataset metadata and returns dataset titles, organisations, descriptions, and links. It does not load the full dataset.
