about the calculations

How it works

This page keeps the technical explanation away from the main user flow. The output is a transparent data case file, not an official forecast.

In plain terms

  • The simulator retrieves historical country-level indicators from the World Bank.
  • It removes blank, null and future-year rows before calculating trend continuations.
  • It loads prepared JSON files for sources that are more reliable as static data.
  • It lists returned records and source rows rather than hiding them behind summary counts.
  • It does not predict conflict, disasters, displacement shocks or humanitarian need.

What “target-year continuation” means

A target-year continuation is a transparent extension of past numeric values into the chosen year. The method depends on the indicator type: population uses compound annual change, percentage indicators are capped between 0 and 100, mortality uses a decline curve, and other numeric indicators use recent straight-line continuation. It is a trend reading, not a forecast.

What the Black Swan stress-test does

The Black Swan section selects a severe stress event using returned evidence: historical disaster types, recent events, climate samples, service proxies and population scale. It is still a scenario stress-test, but its selection is now evidence-linked.
