about the calculations

How it works

This page keeps the technical explanation away from the main user flow. The output is a transparent data case file, not an official forecast.

In plain terms

  • Country case file simulator: builds a country-year evidence file using World Bank indicators, prepared source rows, EM-DAT historical disasters and live context records.
  • It removes blank, null and future-year rows before calculating any World Bank trend continuations.
  • It lists returned records and source rows rather than hiding them behind summary counts.
  • The site does not predict conflict, disasters, displacement shocks or humanitarian need.

What “target-year continuation” means

A target-year continuation is a transparent extension of past numeric values into the chosen year. The method depends on the indicator type: population uses compound annual change, percentage indicators are capped between 0 and 100, mortality uses a decline curve, and other numeric indicators use recent straight-line continuation. It is a trend reading, not a forecast.

What the Black Swan stress-test does

The Black Swan and disaster-pattern stress-test sections select severe events from returned evidence: historical disaster types, recent/current records, climate samples, service proxies and population scale. They create stress-test and pattern-analysis views from historical, current and contextual data. Live records alone do not create forecasts.
